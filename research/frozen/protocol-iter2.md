# Пре-зарегистрированные протоколы проверок (итерация 2)

Заморожено 2026-10-19 до запуска любых проверок. Изменение протокола после старта теста недопустимо: только новая версия файла с новой датой и ссылкой на старую.

## P1 (H001) Асимметричные срезы ансамбля
- Руки: A=1 аналитик, полный контекст; B=3 аналитика, одинаковый контекст (контроль стада; C=3 аналитика, приватные срезы (тест).
- Срезы C: поток (order_flow, order_book_microstructure, derivatives_positioning, liquidations) / контекст (cross_exchange_dispersion, cross_asset_relationships, market_breadth_rotation, stablecoin_flow_proxies, on_chain_activity) / состояние (volatility_regime, time_calendar_session, sentiment_attention, anomaly_novelty, volume_liquidity). Общее ядро у всех: price_returns + цена/режим/факты памяти.
- Метрика: Brier агрегата против фактического hit/miss исхода связки; paired по циклам; percentile bootstrap 95%.
- Стоп: n=300 парных циклов или 45 дней. Success: B−C ≥ 0.01. Kill: |B−C| ≤ 0.005.
- Trials бюджет: 3 (три руки, фиксируются здесь).

## P2 (H002) Внешний калибратор
- Обучающие данные: все разрешённые forecasts, stated prob = planner conviction (clamp 0.4-0.9 фиксируется как есть).
- Калибратор: Beta-Bernoulli по 10 корзинам шириной 0.1, prior α=β=5. Изотоник запрещён до n≥1000 (R03).
- ECE считается на последних 20% исходов по времени (held-out), 10 бинов, только при n≥50.
- Success: ECE_cal ≤ 0.7×ECE_raw. Kill: не улучшается при n≥300. Trials бюджет: 2.

## P3 (H005) Режимные постериоры
- Руки: G=глобальные веса (текущие); W=sliding-window 500 (контроль свежести); R=режимные α,β с λ=0.995 (тест).
- Режим берётся из момента создания гипотезы (поле сохраняется с даты заморозки).
- Метрика: paired hit-rate и expectancy связок, отобранных каждой рукой на одинаковых циклах (через shadow-руку H003).
- Success: R−G ≥ 2 п.п. на окнах смены режима, n≥300. Kill: W объясняет весь выигрыш R. Trials бюджет: 4 (3 руки + выбор λ∈{0.99,0.995} до старта, фиксируем 0.995).

## P4 (H004) DSR-гейт
- Trials: кумулятивный счётчик = Σ offered кандидатов всех циклов + Σ сгенерированных комбинаций (консервативно: обе величины, выбираем offered+combos/100 как эффективные).
- DSR по Bailey-LdP: skew/kurtosis из фактических realizedReturnNet; SR0 = E[max|null] при N=trials.
- Гейт 0.95 применяется к допуску «связка → sizing»; до n=30 на связку — молчание (не допуск).
- Это наблюдательный протокол: успех — гейт воспроизводит картину daru (большинство топов DSR<0.95). Trials бюджет: 1.
