# Дорожная карта: от текущего конвейера к автономной лаборатории

Правило дорожной карты: **фаза закрывается только по измеримому критерию**. «Сделали» не равно «работает». Каждая фаза имеет вход (что должно быть готово), выход (артефакт) и ворота (что должно быть измерено).

Код на момент написания не изменялся — это план, а не отчёт.

---

## Фаза 0. Починить прибор (1–2 недели)

**Зачем.** Пока исход считается не по той цене и не в том окне, любое улучшение модели неотличимо от шума.

**Работы.**
1. Разрешение прогнозов по закрытой свече с `ts >= fixedAt`; хранить `resolution_candle_ts`.
2. Барьеры `k·σ` вместо 35/45 bps; σ — EWMA на момент входа.
3. `RANGE` убрать из P&L-учёта или определить для него исполнимую конструкцию.
4. Издержки как функция `(venue, order_type, size, spread, depth)`; убрать funding из spot.
5. Убрать `clampConviction`; хранить сырую уверенность.
6. Исправить знак funding в `feature-engine.ts`; переименовать прокси.
7. Идемпотентность: уникальный ключ на `(asset, signature, cycle_ts)`, транзакция на цикл.
8. Исправить двойное обучение в `autopilot.ts` (журнал обработанных `forecast_id`).
9. Разрешать прогнозы вне вселенной по реальной цене, а не по `entryPrice`.
10. Ввести `no_trade` как класс исхода.

**Ворота G0.**
- 100% прогнозов разрешаются из закрытых свечей; повторный replay даёт тот же результат.
- Ни один прогноз не остаётся `pending` дольше 2× горизонта.
- Издержки на круг для spot taker ≥ 20 bps, для perp maker ≤ 10 bps — проверено на журнале.

**Риск.** Переписывание evaluator меняет исторические метрики; нужен период двойного учёта (старый и новый расчёт параллельно).

---

## Фаза 1. PIT-хранилище и replay (2–3 недели)

**Зачем.** Без воспроизводимости нет обучения и нет доверия к результатам.

**Работы.**
1. `raw_events` с четырьмя метками времени и хэшем.
2. `feature_snapshots`, `decisions`, `prompt_versions`, `model_versions`.
3. Backfill funding/OI/ликвидций (OKX history endpoints).
4. Replay-движок: снимок → признаки → решение → сверка.
5. `experiment_registry` и `trial_log`.

**Ворота G1.**
- Replay воспроизводит ≥ 99.9% решений и 100% исходов.
- Для любого прогноза можно получить полный входной снимок.
- Журнал испытаний содержит каждое оценённое выражение.

---

## Фаза 2. Paper-брокер и капитал (2 недели)

**Зачем.** Сейчас «профит» не существует как величина.

**Работы.**
1. `orders`, `fills`, `positions`, `equity_curve`, `cash_ledger`.
2. Модель исполнения: taker с impact, maker с очередью и adverse selection.
3. Лимиты: экспозиция, оборот, дневной убыток, запрет новых позиций в стрессе.
4. Метрики: net PnL, Sharpe, Sortino, max DD, turnover, exposure, attribution.

**Ворота G2.**
- Equity curve строится из фактических исполнений, а не из сумм `realizedReturnNet`.
- Расхождение paper-исполнения и replay ≤ 5 bps на сделку.
- Ни один лимит не нарушен за 2 недели прогона.

---

## Фаза 3. Широкое пространство действий и решение (2–3 недели)

**Зачем.** Требование «всегда пытаться» реализуется через выбор действия, а не через принудительный вход.

**Работы.**
1. 12 семейств действий (§6.2 архитектуры).
2. Промпт из шести блоков: рынок, позиция, история, гипотезы, ограничения, действия.
3. Сырые рыночные данные в промпте вместо EVS-скорборда.
4. Структурированный JSON-ответ + валидатор действий.
5. `wait` учитывается в PnL как сэкономленные издержки.

**Ворота G3.**
- Каждый цикл даёт прогноз (вероятность + интервал), даже если действие `wait`.
- Доля `wait` измерена; стоимость пропущенных возможностей посчитана.
- A/B «скорборд vs сырые данные» на одинаковых циклах; победитель определяется по PnL после издержек, а не по hit-rate.

---

## Фаза 4. Обучение (3–4 недели)

**Зачем.** Сейчас обучение — одна формула на 15 категорий.

**Работы.**
1. Калибровка: Brier, ECE, reliability curve, температурное масштабирование.
2. Иерархические веса с полураспадом и pooling по режиму.
3. Дисконтированный Thompson sampling по семействам действий.
4. Детекторы дрейфа на каждый сигнал (ADWIN/CUSUM/changepoint).
5. e-процесс для остановки стратегий.

**Ворота G4.**
- ECE ≤ 0.05 на отложенном периоде.
- Калиброванная вероятность улучшает PnL после издержек относительно сырой уверенности.
- TS не хуже фиксированного правила при том же бюджете риска.
- Хотя бы один детектор срабатывает на искусственно внесённом сдвиге.

---

## Фаза 5. Поиск гипотез и автономность (4+ недель)

**Зачем.** Только теперь LLM получает право генерировать, а не выбирать из готового.

**Работы.**
1. Грамматика выражений + детерминированный evaluator.
2. LLM-мутатор + эволюция с островами и штрафом за сложность.
3. DSR/PBO по всем испытаниям; лимит бюджета.
4. Генерация объяснений и карточек гипотез.
5. Durable scheduler, auth, шифрование ключей.

**Ворота G5.**
- Лучшая найденная программа положительна на отложенном периоде после издержек.
- DSR > 0.95 с учётом всех испытаний.
- Результат воспроизводится из снимка.
- Отключение LLM не ломает цикл (fallback на правила).

---

## Что делать в каком порядке и почему

```
G0 прибор ──▶ G1 PIT ──▶ G2 капитал ──▶ G3 действия ──▶ G4 обучение ──▶ G5 поиск
```

Нарушение порядка — главный риск проекта. Если начать с G5, система будет генерировать всё более изощрённые стратегии для всё более испорченного измерения. Именно это и происходит сейчас: 100 комбинаций на актив при фиксированных барьерах и неверном окне разрешения.

---

## Оценка сроков и стоимости

| фаза | срок | основные затраты | что можно потерять |
| --- | --- | --- | --- |
| G0 | 1–2 нед | инженерные | исторические метрики станут несопоставимы |
| G1 | 2–3 нед | хранение, backfill | время на переиндексацию |
| G2 | 2 нед | разработка | ничего, кроме времени |
| G3 | 2–3 нед | токены LLM | стоимость вызовов при широком промпте |
| G4 | 3–4 нед | вычисления | статистическая мощность при малой выборке |
| G5 | 4+ нед | вычисления + токены | риск переобучения при неограниченном бюджете |

---

## Три сценария провала

1. **Оптимизация шума.** G5 запущен до G0: система находит стратегии, которые работают только в испорченном измерении. Признак — рост in-sample при падении out-of-sample.
2. **Издержки съедают всё.** Широкое пространство действий увеличивает оборот; при 15-минутном горизонте это фатально. Признак — turnover растёт быстрее PnL.
3. **LLM имитирует исследование.** Модель генерирует правдоподобные объяснения без предсказательной силы. Признак — объяснения не коррелируют с исходом; лечится только детерминированным evaluator и DSR.

## Ближайшие три шага (если работа продолжается)

2. Добавить `trial_log` и DSR-калькулятор — без этого нельзя интерпретировать ничего.
3. Прогнать H001 и H008 на сохранённых данных: обе проверяемы без нового источника и дают немедленный ответ о качестве измерения.
